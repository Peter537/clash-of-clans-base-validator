# clash-of-clans-base-validator wiki

Use this reference to record your account inventory, design layouts with explicit coordinates, check them against the model and maintain reviewed rules.

- [Account inputs](accounts.md): counts, mixed levels, max assumptions and overrides.
- [CLI](cli.md): commands, rule selection, reports, exports and exit codes.
- [Layout and profile format](layout-format.md): coordinates, IDs, settings and portability.
- [Designer workflow](workflow.md): LLM design, inspection and manual construction.
- [Visual review](design-review.md): readability and schematic limits.
- [Inventory rules](rules.md): mergers, prerequisites, optional objects and seasonal state.
- [Generated catalogue](catalogue.md): footprints, availability, counts and maximum levels.
- [Sources and conflicts](sources.md): provenance and remaining limits.
- [Updating rules](updating-rules.md): immutable snapshots and reviewed migrations.
- [Verification](verification.md): checks and publication boundaries.

Start with the [TH3 Hi example](../examples/th3-hi/README.md), or follow the [agent skill](../.agents/skills/coc-name-base/SKILL.md). Python checks the layout against the model. The designer reviews visual quality; in-game acceptance remains unconfirmed.
